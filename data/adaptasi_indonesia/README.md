# Adaptasi Indonesia

Folder ini menampung artefak publik/aman untuk P2.

Dataset final 10.000 pesan akan berupa skenario sintetis Indonesia yang diadaptasi secara struktural dari kasus Galloway.

Aturan penting:
- file rekonstruksi verbatim Galloway tetap berada di penyimpanan privat;
- ground truth evaluator tidak ditempatkan pada dataset investigator;
- court record tidak dimasukkan ke RAG eksperimen;
- dataset publik hanya memuat aktor, lokasi, nomor, dan institusi fiktif;
- baris sintetis tidak boleh diklaim sebagai pesan asli kasus Galloway.
