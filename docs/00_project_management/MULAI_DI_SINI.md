# MULAI DI SINI — Daffa / P9–P10

## Tujuan saat Work 10k berjalan
Siapkan evaluasi independen dan kerangka pelaporan sebelum melihat hasil model final.

## Kerjakan berurutan

1. Tetapkan rubrik:
   - factual correctness;
   - evidence attribution;
   - groundedness;
   - hallucination;
   - citation accuracy;
   - contradiction detection;
   - reproducibility.

2. Definisikan unit evaluasi:
   - entity;
   - event;
   - relation;
   - timeline;
   - finding.

3. Buat template blinded evaluation:
   - evaluator hanya melihat evidence/output yang diizinkan;
   - ground truth disimpan terpisah.

4. Buat error register SOLVE-IT:
   - stage;
   - error;
   - impact;
   - detection;
   - mitigation;
   - residual risk.

5. Buat QA checklist per tahap:
   - P1;
   - P2;
   - P3;
   - P4;
   - P6;
   - P7;
   - P8.

6. Review independen corpus 10k pada checkpoint:
   - continuity;
   - actor-state;
   - chronology;
   - duplicate;
   - style;
   - provenance.

7. Buat kerangka laporan:
   - metode;
   - chain of custody;
   - baseline;
   - AI pipeline;
   - evaluasi;
   - error mitigation;
   - limitations;
   - reproducibility.

## Jangan dilakukan sekarang
- jangan menilai performa model yang belum dijalankan;
- jangan membuka ground truth ke tim AI;
- jangan menulis kesimpulan hasil sebelum eksperimen.

## Definition of Done
Rubrik, protokol blind, error register, checklist QA, dan kerangka laporan siap dipakai ketika hasil eksperimen masuk.
