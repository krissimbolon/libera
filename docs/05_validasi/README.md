# Validasi P9

Folder ini digunakan untuk artefak validasi independen tahap P9.

## Ruang lingkup

P9 mengevaluasi hasil eksperimen P8 yang telah dikunci dengan mengacu pada:
- artefak bukti hasil P4;
- baseline forensik tradisional P5;
- output dan log eksperimen P8;
- ground truth privat yang hanya tersedia bagi evaluator sesuai protokol blind.

## Artefak yang akan disimpan

- rubrik evaluasi;
- protokol evaluasi blind;
- checklist gate P9;
- template evaluasi temuan;
- register error berbasis SOLVE-IT;
- dokumentasi hasil validasi final.

## Aturan

- Jangan memasukkan ground truth privat ke repository publik.
- Jangan melakukan scoring performa sebelum output P8 final tersedia.
- Jangan mengubah output P8 setelah ground truth dibuka.
- Setiap hasil evaluasi harus dapat ditelusuri ke RUN-ID dan evidence ID terkait.
