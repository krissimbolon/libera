# Dry Run

Dry-run menggunakan data dummy/non-case untuk menguji:
- Evidence ID;
- hashing SHA-256;
- pembuatan master copy;
- pembuatan working copy;
- verifikasi hash;
- pencatatan chain of custody;
- acquisition log;
- deteksi controlled mismatch.

Jangan gunakan corpus LIBERA final pada dry-run.
